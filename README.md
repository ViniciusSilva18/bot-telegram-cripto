## ✨ Comandos
| Comando | Descrição |
|---|---|
| `/start` | Ajuda |
| `/btc` | Preço Bitcoin |
| `/eth` | Preço Ethereum |
| `/sol` | Preço Solana |
| `/top` | Top 5 por Market Cap |
| `/cripto btc eth sol` | Múltiplas moedas |

## 🛠️ Setup
```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # Adicione o token do @BotFather
python bot.py
```
